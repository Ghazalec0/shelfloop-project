## 🚀 About ShelfLoop

**ShelfLoop** is an advanced web application built to bridge the gap between technical readers and physical/digital library management. It offers an immersive user experience with real-time inventory tracking, integrated payment gateways, an AI-powered reading assistant, and a comprehensive administrative control panel.

---

## ✨ Key Features

### 👤 User & Authentication
* **Secure Auth Flow:** Complete authentication system including Login, Registration, OTP Email Verification, and Password Reset.
* **Bilingual Support:** Full native toggle between English and Arabic with dynamic RTL/LTR layout switching.
* **Dark / Light Theme:** Seamless switching between dark and light modes tailored with custom UI aesthetics.

### 📖 Library & Catalog
* **Advanced Search & Filtering:** Real-time search by title or author, paired with dynamic category filtering.
* **Book Borrowing System:** Borrow books with automated 14-day tracking, return handling, and overdue fine calculations.
* **Permanent Purchases:** Buy books permanently with quantity selectors and multiple payment options (Credit Card, Mobile Wallet, Cash at Library).
* **Favorites Collection:** Save and quickly access your favorite technical books and resources.

### 🤖 Advisor AI
* **Interactive AI Assistant:** Chat with an integrated intelligent assistant to get instant book recommendations, architectural advice, and programming insights in both English and Arabic.

### 🛡️ Admin Dashboard
* **Platform Analytics:** Real-time statistics tracking total books, active borrows, registered users, and engagement rates.
* **Book & User Management:** Add, edit, and delete books with cover image uploads. Manage user roles (Admin/User) and deactivate accounts.
* **Payment Approvals:** Review and approve pending cash payments, fines, and purchase orders.
* **Direct Communications:** Send customized direct email notifications to users for overdue notices or system updates.

---

### 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router, React)
* **Styling & UI:** [Tailwind CSS](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **API Communication:** Axios
